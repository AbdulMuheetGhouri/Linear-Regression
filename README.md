# Linear Regression Implementations

A collection of foundational machine learning implementations focused on Simple Linear Regression and Multiple Linear Regression. This repository demonstrates building, training, and evaluating regression models using Python and Jupyter Notebooks.

---

## Features

- **Simple Linear Regression**: Modeling the relationship between a single independent feature and a target variable.
- **Multiple Linear Regression**: Extending regression analysis to handle multiple input features simultaneously.
- **Data Preprocessing & Visualization**: Handling datasets, splitting train/test sets, and plotting regression lines and metrics.

---

## Getting Started
### Prerequisites
Ensure you have Python 3.8+ installed along with the following packages:

- numpy
- pandas
- matplotlib
- seaborn
- scikit-learn
- jupyter / notebook

### Installation
1. Clone the repository:

```code
git clone [https://github.com/AbdulMuheetGhouri/Linear-Regression.git](https://github.com/AbdulMuheetGhouri/Linear-Regression.git)
```
```code
cd Linear-Regression
```
```code
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```
```code
jupyter notebook
```

Open either simple-linear-regression.ipynb or Multiple Linear Regression.ipynb to explore the workflows.

2. Evaluation Metrics
The models in this repository are evaluated using standard regression metrics:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score (Coefficient of Determination)
